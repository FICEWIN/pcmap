# خريطة الكوكب — The Planet Crafter

خريطة تفاعلية عربية للعبة The Planet Crafter، تعمل على الجوال والحاسوب كتطبيق ويب (PWA).

## ما فيها

- خمسة كواكب: Prime وHumble وSelenea وAqualis وToxicity.
- آلاف المواقع: صناديق عادية وذهبية، مذابح وشيفرات، مواقع هبوط، بذور، مؤن، ومعادن.
- فلاتر لكل نوع، وبحث بالاسم أو النوع.
- تتبع الاكتشاف: اضغط أي علامة ثم «تم التجميع» ليُحسب تقدمك لكل كوكب على حدة.
- دبابيس خاصة مع الاسم والملاحظة والإحداثيات، وتصدير/استيراد نسخة احتياطية.
- «موقعي»: أدخل إحداثياتك من شاشة الخريطة في اللعبة لترى أقرب الصناديق والمعالم.
- «فوق اللعبة»: نافذة خريطة صغيرة، وزر «ثبّت فوق اللعبة» لتثبيتها فوق النوافذ في Chrome/Edge.
- خريطة مزهرة اختيارية بعد التكوين.

## التشغيل محليًا

```powershell
python3 -m http.server 8100
```

ثم افتح `http://127.0.0.1:8100/`.

## المصادر

- بلاطات الخريطة ومواقع الأجسام مبنية على بيانات خريطة المجتمع
  [map.fistshake.net](https://map.fistshake.net/PlanetCrafter/) مع الإسناد الظاهر في التطبيق.
- البلاطات تُجلب عبر بوابة الصور [wsrv.nl](https://wsrv.nl).
- محرك الخريطة OpenLayers 6.15.1 (رخصة BSD).
- لعبة The Planet Crafter ملك Miju Games. هذا التطبيق غير رسمي وللاستخدام الشخصي.

## حدود معروفة

- ليست نسخة من WAND/WeMod: لا تقرأ ذاكرة اللعبة، ولا تحدد موقعك تلقائيًا، ولا تنقل الشخصية.
- التثبيت فوق النوافذ يحتاج Chrome أو Edge على الحاسوب، واللعبة تعمل بوضع نافذة أو بلا حدود.
- بيانات Skeo غير مشمولة حاليًا.
